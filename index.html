Proceso de Análisis

1. Carga

Sube la radiografía digitalizada (PNG/JPG) a nuestra plataforma segura.

2. Procesamiento

Nuestra red neuronal convolucional analiza patrones y texturas del tejido pulmonar.

3. Clasificación

El sistema asigna probabilidades entre 8 categorías diagnósticas distintas.

4. Reporte

Obtén un desglose detallado de la confianza del modelo para cada patología.
